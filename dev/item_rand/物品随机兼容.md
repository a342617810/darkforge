# 随机器「物品随机」和整合包的兼容性

盘点于 2026-11-02（联机开发暂停期间）。现状：启动器和图形界面都提示「不要开物品随机」，开了也能随机化，只是会弹警告；重随（reroll）不知道有没有开物品随机。

## 怎么查的

- 随机器会打乱的物品位置：`randomizer\diste\Base\itemslots.txt`（3200 多个位置，每个位置对应的地图掉落表 / 敌人掉落表 / 商店行编号和标签，`norandom` 的不打乱）。
- 重随改了哪些行：在副本上用原版跑一次重随（`bxtest\safe_reroll_van.py`），和原版 regulation 逐行比（`bxtest\itemrand_conflicts.py`），按改法分类，再和随机器的位置对照。
- 这个整合包还没有成功的物品随机输出（10-19 那几份带 item 的日志是合并 RNG Lands 时失败的），所以「随机器自己会新加哪些行」只能从它的数据里看，没有实测。

## 重随对掉落 / 商店的改法（原版上跑的结果）

| 改法 | 行数 | 物品随机下 |
|---|---|---|
| 原版装备删掉 / 换成未鉴定物品（地图 935、敌人 1960 行；宝箱、Boss、支线奖励里的原版武器防具护符） | 按内容找 | 跟着随机后的位置走，没问题 |
| 黄金卢恩、砥石刀换成未鉴定物品（523 行） | 按内容找 | 同上（砥石刀在随机器的关键道具池里，但不是过关必需的） |
| 骨灰一次性打乱（约 30 行） | 按内容找（道具类型 7 / 8） | 在随机后骨灰所在的格子之间换，没问题 |
| Boss 奖励链后面接龙心脏、星光碎片、锻造石、未鉴定传说；宝箱、白面具后面接行 | 先看后面有没有空号 | 随机器占了的号不会被覆盖，没问题 |
| 召魂铃挪到开局 | 先确认蕾娜那格真有召魂铃 | 随机器默认不打乱召魂铃，没问题 |
| **甲虫掉的战灰（107 行）** | **按固定的行和格子（`data\scarab_ashes.json`）直接改成战灰，不看原来是什么** | **会把随机器放在甲虫身上的东西冲掉**（随机器 107 个甲虫位置全都打乱，可能是护符、法术、骨灰…）。甲虫不是放关键道具的位置，不会卡关，但那些东西就拿不到了 |
| 商人货架：原版装备换成战灰、法术祷告 / 战灰 / 制作笔记在商人之间换、战灰格换成未鉴定 / 小极品 | 按内容找 | 跟着走。随机器会让每个商人的铃珠复制一份打乱后的货架给双子老妪，我们之后改的商人货架不会同步到那份（双子老妪那边可能还卖原版装备） |
| 追忆换取（101800～101999）：武器格换成成品传说，接肢第一格换成战灰、原武器挪到 101949 | 按材料（追忆）+ 类别找 | 随机器会打乱其中 24 个位置；我们只改正好是武器的格子，接肢第一格不管是什么都挪到 101949，还买得到。基本没问题，实测确认 |
| 特殊货币的格子（龙飨祭坛的龙心脏 / 拜尔的心脏、瑟濂的星光碎片）：原版只卖道具和战灰 | 按货币 + 类别找（2026-11-02 补） | 随机器把龙飨祭坛和追忆换取都当「高级商店」（annotations 的 PremiumShop：任意武器、护符、战灰、结晶露滴、法术、古龙锻造石），会放原版装备进来。以前两条规则都不管（「不卖原版装备」只管卢恩格、追忆转换只管材料格）。现在武器换成成品传说（`rr/remembrance.py`，编号表 `SLOTS`：101950～ 650+、102350～ 700+、100300～ 750+，一次性重随 `remembrance_cur`），护符 / 防具 / 表外的武器换成战灰（`shops.gear_to_ash`，`shop_gear_cur`），价格照旧。原版模式输出不变；模拟物品随机（往这些格子塞装备，`bxtest\cur_test.py`）测过，没用随机器真跑 |
| 开局职业装备（CharaInitParam 21 行） | 整行改写 | 随机器打乱的开局装备被整合包的生成装备盖掉（本来就是这么设计的） |
| 新加的行：地图掉落 1335、敌人掉落 14680、商店 1036 | 自己的编号段 | 和随机器列出的位置编号一个都不重；随机器自己新加的道具在 7830000 段（大师钥匙），不撞整合包的 9200 段。随机器为铃珠掉落、提示购买等新加的掉落表 / 商店行编号没列出来，要实测 |

## 结论

**确定有问题的**

1. 甲虫战灰按固定行改，会冲掉随机器放在甲虫身上的东西。改法：只在那一格本来就是战灰时才换（按内容），物品随机下甲虫掉什么就是什么。
2. 双子老妪的铃珠货架（随机器复制的那份）和商人货架对不上：随机器复制之后我们又改了商人货架。改法：铃珠货架那几段也按同样的规则处理，或者照最终的商人货架重新复制一份。
3. 随机器的提示（买的地图标记、spoiler 日志）会指向被我们换掉的东西（比如原版武器那格现在是未鉴定物品）。只是提示对不上，不影响通关。

**要实测的**（开物品随机 + 敌人随机随机化一次，在副本上重随）

1. 重随会不会报「编号已被占用」（随机器新加的行撞上整合包固定编号的新行：发货表 11000～11031、暗黑商店 114000～119115、说明书等）。
2. 开了敌人随机时，重随按敌人实际位置换掉落表（`stage3`），随机器放在某个敌人身上的掉落还在不在。
3. 关键道具在 Boss 奖励链里时，我们往链后面接东西后，关键道具还能拿到。
4. 随机器改过的事件（事件发放的物品）和我们合并进去的公共事件一起是否正常（`scripts.py` 按最后生效的那份合并，应该没问题）。

**没问题的**：删原版装备、未鉴定物品掉落、骨灰打乱、Boss 奖励、召魂铃、追忆换取（基本）、关键道具（我们按内容改的规则都不碰道具类的关键道具，唯一按固定行改的甲虫位置随机器不放关键道具），所以目前看不会卡关。

## 开了以后实际会打乱什么（按现在的设计）

整合包现在给随机器的选项里，`norandom`（关键道具不打乱）、`norandom_health`（黄金种子、圣杯露滴不打乱）、`norandom_upgrades`（锻造石铃珠不打乱）、
`norandom_scadu`（幽影树碎片、灵灰不打乱）都开着；`weaponprogression` 让锻造石大体按地区分布、接近原版。打开「物品随机」后，随机器打乱剩下的东西，重随再按整合包的规则处理：

| 东西 | 随机器 | 重随之后 | 玩家实际感受 |
|---|---|---|---|
| 原版武器、防具、护符 | 打乱（地上、宝箱、Boss、敌人、商店、开局） | 全删：地上 / 敌人 / Boss 的删掉，宝箱和支线奖励里的换成未鉴定物品，商店的换成战灰 | 和现在一样拿不到原版装备；只是哪些宝箱、哪些支线给未鉴定物品跟着变 |
| 法术、祷告 | 打乱（地上、商店） | 商人之间再换一次；暗黑商店打倒满月女王后全卖 | **会变**：前期可能捡到强力法术，商人卖的也不一样 |
| 骨灰 | 打乱 | 在骨灰格之间再一次性打乱 | 和现在差不多（现在本来就打乱） |
| 战灰 | 打乱 | 甲虫按固定格子改回战灰（要修成按内容）、商人的战灰格换成未鉴定 / 小极品、暗黑商店全卖 | 基本没差别 |
| 消耗品、材料、制作笔记、锻造石、黄金卢恩、其他铃珠 | 打乱（锻造石大体按地区） | 黄金卢恩、砥石刀那格换成这个地区的未鉴定物品；其余不动 | **会变**：地上捡到的东西换了，未鉴定物品的光点跟着黄金卢恩的位置走 |
| 关键道具、护符皮带、记忆石、砥石刀、黄金种子、圣杯露滴、锻造石铃珠、幽影树碎片、灵灰 | 现在的选项不打乱（护符皮带 / 记忆石 / 砥石刀跟关键道具一起处理，实测确认） | — | 不变。玩家在随机器里打开关键道具随机也行，整合包的规则不碰这些 |
| 商人货架 | 打乱，双子老妪的铃珠货架照它复制 | 原版装备 → 战灰，战灰格 → 未鉴定 / 小极品，法术祷告和制作笔记在商人之间换 | 会变；双子老妪那边对不上（要修） |
| 开局职业 | 打乱开局装备 | 武器、防具、开局遗物换成整合包生成的 | 武器防具和现在一样；随机器给的别的东西（法术、道具）可能留着，和生成的武器不一定配得上（实测看） |
| 敌人掉落 | 特定敌人的掉落打乱 | 原版装备删掉，后面接未鉴定物品 | 少数敌人掉的稀有东西变成别的道具；未鉴定掉落照旧 |
| 整合包加的（Boss 的龙心脏 / 星光碎片 / 融锻之心 / 保底锻造石 / 传说，敌人的未鉴定掉落，宝箱追加，商人的小极品，暗黑商店，追忆换取的传说，大蛇狩猎矛，说明书，开局召魂铃） | 随机器之后才加 | 固定在原来的地方 | 不变 |

一句话：开物品随机后，原版装备那部分没有意义（整合包本来就全删了）；真正有差别的是法术祷告、消耗品和材料、锻造石、制作笔记这些「道具」的位置和商人货架。关键道具打不打乱由随机器的选项决定，整合包不碰。

## 已做（2026-11-02，v0.8.7 未发布）

- **重随认出物品随机**：`reroll.py` 的 `rand_options` 读随机器最近一次成功的 spoiler 日志第一行，选项里有 `item` 就 `ctx.item_rand = True`。开着时：
  - 商店重抽（法术祷告 / 战灰 / 制作笔记在商人之间换）跳过：随机器已经打乱过商店，双子老妪的铃珠货架也就和商人对得上（上面「确定有问题」2）；
  - 骨灰一次性打乱跳过（随机器已经打乱过）。
- **甲虫身上的原版装备换成随机战灰**（2026-11-24，用户「甲虫那个改成随机战灰」）：随机器放到甲虫身上的原版武器 / 防具 / 护符以前被 `bosses.no_weapons` 删成什么都不掉；现在 no_weapons 记下删掉的格子（`ctx.gear_stripped`），`shops.scarabs` 把甲虫行里这些格子和本来是战灰的格子一起从全部战灰里随机分（开了物品随机时不再优先放「只有甲虫掉」的那些）。模拟测试（副本重随时报告物品随机开着，重随前把甲虫格换成武器 / 防具 / 护符 / 法术 / 战灰各约 10 只）：装备和战灰 41 只都掉战灰（41 种不重样），法术 10 只照旧。没用随机器真跑。
- **甲虫战灰按内容改**（`shops.scarabs`）：只改这一格现在就是战灰的，随机器放在甲虫身上的别的东西不动（上面「确定有问题」1）。没开物品随机时 51 只甲虫都是战灰，结果和以前一样（一次性记录照旧沿用）。
- **启动器 / 图形界面**：不再劝玩家关物品随机，改成说明开了会打乱什么；状态卡片显示「含物品」；只开物品随机、没开敌人随机的结果也算有效（启动前不再提示「和无敌人随机差不多」，更新后也能沿用）。
- **随机器主按钮识别**（`randomize.ps1` 的 `Find-RandButton`）：按钮文字随选项变（「随机化敌人」「随机化物品与敌人」「以设定种子运行随机」「运行新一轮随机！」……），
  以前只认「随机化 / Randomize」开头，开了物品随机又用固定种子（联机随机码）时认不出来，等 90 秒后把随机器关了。现在从随机器自己的界面文字
  （`diste\Messages\*.json` 的 `EldenForm_randomize*`）收集全部写法（79 种，各语言）。

## 实测（2026-11-02）

随机器输出事先备份（`bxtest` 外的 `s8_backup`），测完恢复（核对码回到测试前）。

- 选项：现在的默认选项 + `item`，**去掉 `norandom`（关键道具也打乱，条件更严）**，固定种子 20261102；随机器自动点「以设定种子运行随机」成功，输出地图 510 张。
- 在副本上重随（`bxtest\safe_reroll.py`）：成功；报告里骨灰、商店重抽显示「开着物品随机，跳过」，甲虫只有 1 只本来是战灰。
- `bxtest\itemrand_check.py`（随机器输出 vs 重随结果）：地图掉落 + 商店里 1191 种道具一样没少；敌人掉落里 516 种都还在；**44 种关键道具 / 护符皮带 / 记忆石等全在**。
- `bxtest\itemrand_npc_check.py`（每个敌人参数自己的掉落）：3554 处里 8 处不掉了，都是 Boss 战召唤出来的随从（`data\boss_summons.json`，整合包本来就让它们不掉东西，原版里掉的也只是材料），不是随机器的物品位置。
- 没开物品随机的原版、只开敌人随机两种重随结果照旧（骨灰、商店、甲虫都是「沿用第一次抽的」）。

**还没在游戏里玩过**开物品随机的存档（进游戏看商店、宝箱、Boss 奖励）。
