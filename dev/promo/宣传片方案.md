# 暗黑重铸（Darkforge）宣传片方案

2026-11-11 重写，按 v0.10.1 的内容写，替换 2026-11-01 的旧版（那时还叫 Dark Reforged，v0.8.5）。本文只是方案，没有改任何 mod 代码、数据和游戏文件。
资料来源：`更新日志.txt`（v0.8.5 ~ v0.10.1）、`说明\启动说明.md`、`dev\narrative\叙事方案.md`、`dev\title_menu\`（两张标题封面）、`dll\dark_core\affixes.txt`（词条和流派）、记忆目录里各功能的笔记。

## 和旧版比改了什么

- **名字**：暗黑重铸 / Darkforge。英文里不能再出现「Reforged」（和 ELDEN RING Reforged 撞名，这也是改名的原因），旧版的英文宣传语「The Lands Between, Reforged.」作废。
- **结构**：改成两幕，正好对应两张标题封面。第一幕「重铸」是普通难度：橙色炉火和四色重铸环，讲刷宝和流派；第二幕「步入死亡」是死亡以上难度：紫色魇火和咒痕纹章，讲咒痕、魇化精英和超限。两幕之间用标题画面从普通封面叠化成魇火封面来转场。
- **新卖点**：死亡以上难度一整套（七道咒痕、魇化精英、魇火、魇印、超限锻造石、许愿石、馈赠）；骨灰稀有度和词条；斗技场试炼；鉴定拆成一键鉴定和按武器类型、部位、流派的定向鉴定；装备工坊的词条百科和超限页；145 种专属战技做成战灰，范围战技放大到 8 米；低血流派；新启动器（动态封面背景、检查更新）。
- **词条变了，镜头跟着换**：
  - 心流不再掉落，姿态舞不再拍金色心流；
  - 处刑改成致命一击后自身加速；
  - 见切减速提到 90%，影步定身 3 秒，画面效果比以前明显得多；
  - 新增相杀（出招时也能挡下攻击、冒防御火花）、乘势、无形、盈满（法球最多 7 颗）；
  - 沉稳改名寸劲，鹰眼视觉改名盈满。
- **文案**：去掉「交界地，你已经走过一遍了」「但这一次——」这类先铺垫再转折的句子，改成原版说明那样平铺直叙；能用游戏里已有的句子就直接用（第 2.2 节）。
- **录制**：OBS 的「游戏采集」录不到装备工坊、魇印、咒痕这些界面（它们画在游戏画面上面，游戏采集抓帧时还没画上），改用「显示器采集」（第 4.1 节）。
- **授权**：敌人信息 mod 已经拿到作者许可；随机器整合包已经不再附带，但「一键重随敌人」还会自动点随机器的按钮；改版追忆 Boss 的授权大多没定，**改版拉塔恩拿不到许可**（第 6.2 节）。
- **不再宣传**：联机按钮已经隐藏，片子里不提联机。

## 0. 一页看完

- 做三个版本：**30 秒预告**、**约 2 分钟主宣传片**、**约 5 分钟功能介绍**；可选再做 **「步入死亡」60 秒预告**（给硬核玩家）和 **流派短片系列**。
- 推荐顺序：先一次性录好素材库（第 4 节），先剪 **2 分钟主片**，30 秒预告和竖屏版从主片里剪；5 分钟介绍等配音定了再做。
- 30 秒和 2 分钟用 **纯字幕 + 配乐**；5 分钟需要旁白（第 3.4 节有全文）。
- 有几个镜头一个角色只能拍一次（头目首杀、第一次进入「死亡」、咒痕反转），要按第 4.3 节提前备份存档。
- 公开发布前要先定：随机器、改版 Boss 在片子里怎么出现，完整整合包放哪下载（第 8 节）。

## 2. 叙事线和文案规矩

### 2.1 两幕结构

| | 第一幕「重铸」 | 第二幕「步入死亡」 |
|---|---|---|
| 封面 | 普通封面：炉火、烟雾、四色重铸环（白 → 蓝 → 紫 → 金，正好是四档稀有度） | 魇火封面：紫色烟雾、七段咒痕纹章 |
| 色调 | 暗底 + 橙色炉火 + 金色 | 暗紫底 + 紫色烟雾 + 粉紫光 |
| 内容 | 掉落 → 鉴定 → 流派 → 打造 → 骨灰 / 斗技场 | 封印解开 → 咒痕 → 魇化精英 → 魇火 / 魇印 → 超限 → 咒痕反转 |
| 配乐 | 史诗、明亮一些的管弦 | 低沉合唱、更重的打击 |

### 2.2 能直接用的游戏内句子

这些句子已经在游戏里（用户定过的叙事文案），片子里拍到游戏画面时就让游戏自己的字当字幕，后期不再另配一行：

| 出处 | 句子 |
|---|---|
| 未鉴定武器的说明 | 来历不明的武器。表面的流纹文字已经模糊，无法辨认。 |
| 加载提示「流纹文字」 | 装备上的词条，是钢铁皱褶内的流纹文字。在远古时代，铁匠用这些文字固定武器的灵魂。 |
| 第一次进入「死亡」的提示 | 命定之死的封印解开了。 / 身上刻下了七道咒痕。 |
| 咒痕反转的提示 | 咒痕「…」已反转为祝福 + 每道一句（比如「血红的印记化作了金色。」） |
| 七道全部反转 | 七道咒痕尽数化为祝福。 |
| 暗黑商店上新 | 暗黑商店新增了交易项目。 |

### 2.3 文案规矩

- 照原版说明文字的写法：直接陈述，不用「不是……是……」、不用先铺垫再反转、不抖机灵（用户对游戏内叙事文字的要求，宣传片照同样标准）。
- 玩家看到的字：叫「新装备 / 新武器 / 新防具」，不叫「生成装备」；不写「DLC」，写「幽影之地」、需求写「《黄金树幽影》」；不出现 dll、重随、文件名。
- 原版用语照原版：观察力（不是发现力）、交界地、赐福、褪色者、步入死亡、减伤率。
- 英文字幕里的系统名照游戏内英文：Gear Workshop、Nightmare elites、Nightmare Embers、Seals（魇印）、Cursemarks（咒痕）、Overlimit Smithing Stone、Colosseum Trial、A Gift to the Daring、Fusion Heart。出英文版前对一遍英文界面。

## 3. 版本和分镜

### 3.1 通用约定

- **节奏**：按 120 BPM 写（1 拍 = 0.5 秒，1 小节 = 2 秒）。选定配乐后把时间码整体平移到实际拍点上，镜头里「命中那一下」对准小节第一拍。
- **素材编号**：`S01`… 对应第 4.5 节素材清单。
- **字幕**：中文主字幕在下，英文小一号在下面（英文版去掉中文）。流派名用左下角的「名卡」（样式见第 5.3 节）。画面里已经有游戏文字时不再加字幕。
- **不改速度**：演示机制的镜头不加速、不慢放（见切的减速是游戏里真的减速）。只有空镜和转场能变速。

## 4. 素材拍摄计划

### 4.1 录制设置

**素材目录**（`D:\film\darkforge_bili\`，D 盘是电脑里的固态，剩余约 369 GB）

| 文件夹 | 放什么 |
|---|---|
| `素材\` | OBS 录像直接存这里；文件名带镜头编号，如 `S05_头目首杀.mkv`；有好瞬间顺手记时间，如「见切在 0:23」 |
| `配乐\` | 曲子（wav 或 320k mp3）和授权证明；曲库标了 BPM 的话一起记下 |
| `预览\` | 剪辑出的小尺寸预览片，看完给意见 |
| `成片\` | 最终成片和封面图 |
| `work\` | 名卡、字幕、中间文件（剪辑用，不用管） |

剪辑用 ffmpeg 9.0.2（已装，显卡编码和中文字幕都测过）。本方案的副本也放在这个目录里，改方案时两份一起改。

**OBS**（33.0，这台电脑：主显示器 1920×1080@60，另有一块竖屏副屏，显卡 RTX 3060 Ti）

| 位置 | 设置 |
|---|---|
| 来源 | 「显示器采集」，选**主显示器**（1920×1080 那块，不是竖屏）；关掉「捕获鼠标指针」 |
| 视频 | 基础分辨率、输出分辨率都设 1920×1080；帧率 60 |
| 输出 | 输出模式选「高级」 → 录像 |
| 录像路径 | `D:\film\darkforge_bili\素材` |
| 录像格式 | mkv |
| 编码器 | NVIDIA NVENC HEVC；码率控制 CQP，CQ 16；预设 P5；关键帧间隔 1 秒 |
| 音频 | 采样率 48 kHz；只录桌面音频，麦克风关掉 |
| 回放缓存 | 开启，120 秒 |
| 热键 | 开始/停止录像 F10，保存回放 F11（F9 留给开发者工具） |

- **用「显示器采集」，不要用「游戏采集」**：装备工坊、魇印、咒痕、词条百科这些界面画在游戏画面上面，游戏采集抓帧比它早，录出来是空的。另外两个办法（游戏采集勾「捕获第三方叠加层」、窗口采集）都能试，但没在 DX12 上确认过，正式录之前先各录 10 秒看看。敌人信息 mod 的血条可能是同样的情况，一起检查。
- 游戏设成「无边框窗口」，显示器采集最稳；显示器采集会把 Windows 通知也录进去，所以要开勿扰模式。
- 分辨率：按显示器原生录，这台是 1080p60。竖屏短片要从横屏裁，1080p 裁出来偏糊，以后做竖屏版再考虑。
- 编码：RTX 3060 Ti 没有 AV1 编码，用 NVENC HEVC（见上表）。
- 录成 **mkv**（游戏崩了文件也不坏），不用转封装，ffmpeg 直接读。
- 游戏声音单独一轨，麦克风关掉。**铁砧声、鉴定提示音、冲击波、唤声船的铃声都要录进去**，剪辑要用。
- 开 **回放缓存**（120 秒，按 F11 保存）：见切、连锁、凌空这种「刚好成了」的镜头，打出来再按键存。

**启动器**
- 用「窗口采集」单独录启动器窗口，录之前拖到屏幕中间。
- 两种背景都录：「工具与设置」→「界面」里能切普通 / 魇火背景、开关烟雾动画。录完把这些设置改回自己习惯的样子。
- 状态卡片、日志里有游戏路径（带 Windows 用户名），后期打码。

**游戏设置**
- 画质拉满；动态模糊关掉；亮度保持默认。空镜时镜头灵敏度调低，用手柄推镜头。
- HUD：电影镜头设「自动」（脱战时大部分界面隐藏）；功能镜头保留 HUD，状态图标的层数、光效、获得提示都是卖点。
- 敌人信息 mod（敌人头上的血条、状态条）：在启动器「工具与设置」→「游戏」里开关，下次启动生效。功能镜头开着（看异常条、血条），电影镜头关掉。
- 游戏语言：中文版用简体中文；**英文版要用英文界面再录一遍界面镜头**（说明、赐福菜单、工坊、咒痕页、屏幕中间的提示），战斗镜头共用。先做 B 站中文版，英文界面镜头以后再录。

**电脑**
- 勿扰模式；关掉 Steam、Discord 的弹窗和游戏内叠加层、帧数显示。
- F9 开发者工具用完先按 F9 关掉，画面里不能出现它。

- 骨灰的稀有度、词条和机制前缀（爆裂、殉道……）；

- 唤声船、熔炉百相之羽（飞行防卡墙改过）；
- 装备工坊的搜索和筛选；
- 进入「死亡」时的叙事提示。

### 5.1 软件

- DaVinci Resolve（免费版够用）或剪映专业版；时间线 60 fps，分辨率和素材一致。
- 主片做好后存一份「无字幕版」时间线，英文版、竖屏版、系列都从它派生。

### 5.2 Logo 和标题字

- **Logo 就用游戏里的标题画面**（S01、S02）：DARKFORGE 和「暗黑重铸」本来就在上面，还是动态的，比剪辑里另做的更统一。结尾卡把文字叠在环下面的空处，不挡标题字。
- **不要在剪辑软件里重新排「DARKFORGE」**：封面上这几个字母用的是游戏自带的 Agmena 字体，剪辑软件里装来用要另外授权。要单独用英文名时，用 Cinzel 这类免费字体，或直接截录下来的标题画面。
- **缩略图、封面图别把「ELDEN RING」字样当成我们的 Logo**：标题画面作为游戏画面出现没问题，单独做图时以「暗黑重铸 DARKFORGE」和重铸环为主，「《艾尔登法环》mod」写成小字。
- **字体**（都能免费商用）：
  - 中文标题：**龙藏体**（和封面上的「暗黑重铸」同一款，SIL OFL）；
  - 英文标题：Cinzel 或 Cormorant Garamond；
  - 字幕：中文思源黑体 Medium 或思源宋体 SemiBold，英文 Cormorant Garamond / EB Garamond。
  - 不要用游戏自带的中文字体（方正书宋）：方正字体商用要授权。
- **重铸环当小图标**：启动器的任务栏图标就是四色重铸环（`launcher\darkforge.ico`，预览 `dev\title_menu\covers\icon_preview.png`），可以当频道头像、片子角标和章节标记。

### 5.4 转场和节奏

- 卡拍硬切为主；第一幕内的段落之间用金线横扫或黑场。
- **两幕之间只用一次「封面叠化」**：普通封面的四色环淡出，魇火封面的七段咒痕淡入，烟雾从橙变紫。这一下是全片的转折点，前后都留白。
- 获得物品的提示、屏幕中间的提示本身就是很好的转场。
- 闪白全片最多两次（爆发段进入、最后一击）。
- 游戏音效保留：鉴定提示音、铁砧声、冲击波、处决那一下压在音乐下面，音乐在这些地方让一下。

### 5.5 配乐

**方向**
- 第一幕：混合管弦预告片风格（弦乐、铜管、打击乐），温暖、昂扬；流派段要有明显的「爆发」。
- 第二幕：低沉的合唱和更重的打击，暗、压迫；咒痕反转时转一点明亮收尾。
- 最省事的做法是挑一首自带「前奏 → 爆发 → 安静 → 再起 → 高潮」段落的预告片曲，安静段正好放封面转场；找不到就第一幕、第二幕各一首，在转场处接。
- 5 分钟介绍：低调的氛围铺底，不抢旁白，比旁白低 18~24 dB，章节换段。

**版权**
- **不要用《艾尔登法环》原声**：YouTube 会被 Content ID 认领或屏蔽，B 站也可能被判侵权。
- 用能商用、能跨平台的曲库：订阅制（Epidemic Sound、Artlist 等）一般同时覆盖 B 站和 YouTube；免费的（YouTube 音频库、Pixabay Music 等）逐首看授权；B 站投稿工具自带的曲库通常只授权在 B 站内使用。
- 每首曲子保存授权证明，简介里按要求署名。

### 5.6 封面图和简介

- **封面图**：两种思路。一是左橙右紫，中间一道裂开的重铸环，对应两幕；二是单用普通封面的四色环 + 背景虚化的传说图标墙。大字「暗黑重铸」用龙藏体，小字「《艾尔登法环》刷宝整合 mod」。准备 16:9 和 4:3 两种裁切，YouTube 用 1280×720。
- **B 站标题示例**：
  - 【艾尔登法环 mod】暗黑重铸 Darkforge：随机词条新装备、十一个流派、七道咒痕
  - 【艾尔登法环】刷宝整合「暗黑重铸」宣传片｜鉴定、重铸、步入死亡
- 「暗黑式」「类暗黑」当玩法描述可以，不要用《暗黑破坏神》的 Logo 或画面。
- **简介模板**：
  1. 一句话介绍 + 六个卖点；
  2. 下载地址（完整整合包；以后的版本启动器里「检查更新」就能更新）；
  3. 需求：正版《艾尔登法环》和《黄金树幽影》，游戏版本 1.17.1 / 1.17.2，Windows 10 / 11；
  4. 安装三步：解压、双击「启动.bat」、一键启动；
  5. 敌人随机：要自己下载 thefifthmatt 的 Elden Ring Randomizer（N 网 428），启动器会提示放到哪；
  6. 敌人信息 mod 的稳定性提示，以及它能在启动器里关掉（作者许可的条件）；
  7. 反馈方式、致谢（第 6.2 节）、免责声明、配乐署名、AI 声明（如果用了）。

### 6.3 其他

- **AI 内容声明**：N 网要求标注 AI 生成的内容（mod 的代码大部分是 AI 写的）；宣传片用了 AI 配音或 AI 生成的画面，B 站投稿时按平台要求声明。
- **版本号**：片子里不写死版本号，版本号放简介。v0.10.1 之后有改动的话，回头核对字幕和镜头。
- **不夸大**：片子里的机制都要是游戏里真能打出来的样子；不加速、不慢放演示镜头；不拿开发者工具才有的效果当卖点。
- **剧透**：用到幽影之地或最终头目的画面时，简介里提一句。
- **隐私**：启动器路径、Windows 用户名、Steam 好友弹窗都处理掉。

## 7. 推荐的执行顺序

1. 定第 8 节的几件事（尤其是授权怎么处理、完整整合包放哪下载）。
2. 按 4.1 准备录制环境（先确认显示器采集能录到装备工坊），按 4.2 准备存档，过一遍 4.4 的实测清单。
3. 按 4.6 的日程录素材；4.3 的镜头先备份再录。
4. 粗剪 2 分钟主片 → 选定配乐后卡拍精剪 → 字幕、名卡、结尾卡。
5. 从主片剪 30 秒预告和竖屏版；做封面图。
6. 跟公开发布一起发（B 站先发），社区帖带 30 秒或 GIF。
7. 写定旁白、录音后做 5 分钟介绍；之后做「步入死亡」预告和流派系列。
