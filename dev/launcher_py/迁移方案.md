# 启动器从 PowerShell 迁移到 Python

起因：2026-11-18，测试者的火绒把发布包报成 `Backdoor/Meterpreter.q`。用户决定 「直接整体迁移」。

## 目标

- 包里不再有 `.ps1`，`启动.bat` 也不再调用 powershell。所有逻辑都用包里自带的 Python（`launcher\python`）跑。
- 玩家看到的界面、按钮、流程、启动日志（`§` 行）和写出的文件格式都不变。
- 网页界面的设置（localStorage：`df.mode` / `df.bg` / `df.anim` / `df.autocheck`）照样保留。做法是继续用同一个用户数据目录 `%LOCALAPPDATA%\Darkforge\WebView2`，以及同一个虚拟主机 `https://darkforge.local`。

## 已经验证的

- **Python 直接驱动 WebView2（2026-11-18，`scratchpad\wv2poc`）。** 只用 ctypes：Win32 窗口加包里的 `WebView2Loader.dll`。网页发消息给宿主、宿主回复、网页再回一条，一共 0.38 秒，中文正常。不需要任何第三方库。
  - 各接口方法的槽位号是从包里的 `Microsoft.Web.WebView2.Core.dll` 读出来的。
  - 一个坑：WebView2 自己也会发 WM_TIMER，要按窗口和计时器编号区分。
  - 另一个坑：在 Claude 的命令沙盒里建不起控件，测试要在普通终端里跑。
- **还没验证：** 随机器窗口用 UI 自动化。随机器是 Avalonia 程序，按钮和勾选框没有自己的窗口句柄，只能走 UIA 的 COM 接口（同样用 ctypes）。

### 入口

- `启动.bat` → `pythonw -I launcher\spawn.py`。spawn.py 改成直接启动 Python 界面。
- spawn.py 仍然认 `gui.ps1` 和 `launcher.ps1 -Action watch -GamePid N` 这两个旧写法。老版本的启动器在线更新完会用它们重开自己，这样更新到新版后也能接着打开新界面。
- 经典界面不迁（用户规则：经典界面不维护）。
- 电脑上没有 WebView2 运行库时：弹一个系统对话框说明情况，并给出微软的下载链接。现在的做法是退回经典界面。

## 避免误报的写法约定

- 不启动 powershell 和 cmd，也不用隐藏窗口的方式启动它们。
- 不在运行时编译代码（没有 Add-Type 了），不把数据「base64 + 解压」以后执行。联机码解出来只是文本。
- 不读杀毒软件状态，不改系统设置，不写注册表（只读 Steam 路径和显卡信息）。
- 不用 PyInstaller 之类的工具打成 exe（那种 exe 最容易被误报），继续用包里的 python.exe / pythonw.exe 直接跑 `.py`。

## 要照原样保留的行为（清单里查出来的坑）

- **大小写。** PowerShell 的比较、哈希表键、`-match` 都不分大小写。`Sort-Object` 按区域规则排序，而且不分大小写；mod 的加载顺序靠它，Python 要用一样的排序键。
- **写出的文件格式。**
  - UTF-8 无 BOM、CRLF：`YAFSML.ini`、`randomizer_settings_path.txt`、`packs.txt`、随机器的 `user.config`。
  - 带 BOM：`erd_tools.ini`、`YAFSML自定义.ini`、`save_ops.txt`、诊断包里的文本。
  - `ersc_settings.ini` 保持原来有没有 BOM。
  - 无 BOM、LF：`.preset`、`coop_profile.txt`、`bossmods.txt`。
  - `hi_source.json`、`backup_info.json` 照 PowerShell `ConvertTo-Json` 的排版写。
- **备份去重签名。** 格式是 `完整路径|大小|修改时间 Ticks`，Ticks = `st_mtime_ns // 100 + 621355968000000000`。格式不一样，已有的备份就会被当成新的。
- **随机器的 user.config。** 要用文本方式改，保留 `xmlns:xsi` / `xmlns:xsd`。
- **玩家自己存成 GBK 的 `YAFSML自定义.ini`。** 读的时候要容错（`errors='replace'`）。
- **崩溃看守。** 游戏一启动就打开进程句柄，退出后才读得到退出码；游戏窗口用 EnumWindows 找；启动时间用 GetProcessTimes；轮询间隔和等待时间照抄。
- **顺手修两处老问题。**
  - 等随机器结果时，日志开头的说明里就有「Basic placements」，没看到「随机中」的那条路径可能提前判成成功。
  - `reroll\savediff.py` 还按 `.co2` 认联机存档，现在联机存档叫 `.rngcoop`。

## 分阶段

迁移期间旧的 PowerShell 启动器一直是默认的。新启动器另开一个开发用入口（不打包）来试，等到第 5 步才切换。

1. **核心库 + 命令行：** launcher.ps1 的非界面部分，加上 backup / usermods / coopcode。
   - 对照测试：用假的 APPDATA、同样的输入，分别跑 PowerShell 版和 Python 版。YAFSML.ini、备份目录、角色记录、设置文件、日志里的 `§` 行都要逐字节一样。
2. **随机器自动操作（UIA）+ 死亡以上世界第二遍。** 在副本目录上实跑随机器。
3. **网页界面：** 宿主、状态模型、页内对话框、文件选择框、后台进程弹框。在普通终端里实开窗口，逐个按钮试。
4. **诊断包和崩溃看守。**
5. **切换：**
   - 改 `启动.bat`、spawn.py、make_package（去掉 `.ps1`）。
   - 在副本上验证「老启动器在线更新到新版再重开」这一步。
   - 更新说明文档，删掉 `.ps1`。
   - 这一版要发完整包还是增量包，到时再定；增量包可以删文件，`launcher\python` 本身不用改。

### 旧代码里查出来的老毛病

这次都照原样搬了过来，要不要修待定。

| 处 | 问题 |
