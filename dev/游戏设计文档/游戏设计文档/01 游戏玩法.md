# 游戏玩法

**负责人：** xp271 · **状态：** 按 v0.10.12 的实现整理 · **上次审阅：** 2026-11-17

玩家照常在原作的世界里探索和战斗。变化有两处：掉落换成了要鉴定的新装备；赐福菜单最上面多了一个「暗黑重铸」。

支柱编号：① 每件装备都是掉出来的　② 词条改变打法　③ 长在原作里　④ 开箱即玩，不碰原版　⑤ 难度越高，给得越多（见[游戏设计文档](../%E6%B8%B8%E6%88%8F%E8%AE%BE%E8%AE%A1%E6%96%87%E6%A1%A3.md)）。

## 核心循环

```mermaid
flowchart LR
  n0["出发：选区域、定难度"]
  n1["探索战斗"]
  n2["拾取未鉴定物品"]
  n3["赐福鉴定"]
  n4["打造：工坊、商店、出售"]
  n5["换装、调整流派"]
  n0 --> n1
  n1 --> n2
  n2 --> n3
  n3 --> n4
  n4 --> n5
  n5 --> n0
```
_核心循环，每轮约 15～30 分钟（估计，没有统计过）_

| 环节 | 典型时长 | 玩家面对的问题 |
| --- | --- | --- |
| 出发 | 1 分钟 | 去下一片区域，还是回头清前面的？要不要调高难度，换更多卢恩和观察力？ |
| 探索战斗 | 10～20 分钟 | 要不要去打精英（按下一个地区的标准掉落）和野外头目（首杀多给传说）？ |
| 拾取 | 随战斗进行 | 新装备快到持有上限了，先回去卖掉，还是继续打？ |
| 鉴定 | 1～3 分钟 | 一键鉴定碰运气，还是花卢恩定向鉴定成想要的武器类型、防具部位或护符流派？ |
| 打造 | 2～5 分钟 | 融锻之心转哪一条词条？重铸石重抽哪一把？卢恩拿去升级、许愿，还是留着定向鉴定？ |
| 换装 | 1～2 分钟 | 新词条接得上现在的流派吗？还是换一个流派重新凑？ |

核心循环外面还套着三个大循环：

- **区域**：打倒区域头目 → 暗黑商店上架这片区域的法术、祷告、战灰和箭；头目首杀给传说、龙心脏、星光碎片和锻造石，追忆头目另给融锻之心。
- **死亡以上**：
  - 魇化精英死在附近 → 它的词条变成魇火（最多 3 个，死亡后消失）→ 同一条夺取够次数，刻成永久的魇印；
  - 区域头目首杀 → 咒痕碎片 → 集满 5 片，这道咒痕反转成祝福；
  - 头目还给超限锻造石、许愿石和骨灰。
- **斗技场**：花星光碎片 → 2 / 4 / 8 波连战 → 每波的未鉴定物品和骨灰直接进背包。

## 机制

| 机制 | 玩家做什么 | 服务的支柱 | 状态 |
| --- | --- | --- | --- |
| 未鉴定物品 | 敌人、宝箱、头目额外掉落；地上的黄金卢恩和砥石刀也换成未鉴定物品 | ① | 已上线 |
| 一键鉴定 / 定向鉴定 | 一键：背包里的全部随机鉴定；定向：选武器类型、防具部位或护符流派，再选稀有度，按稀有度付卢恩 | ① | 已上线 |
| 四档稀有度 | 普通、稀有、史诗、传说；幽影之地的传说再高一档，词条更多 | ① | 已上线 |
| 新武器 | 以原版武器为本体，随机补正、能力需求、属性（纯物理 / 物理加一种元素 / 纯元素）、附加异常、战技和特效；五项都有补正的叫全能武器 | ①② | 已上线；九种属性的伤害游戏内未完整验证 |
| 防具和护符词条 | 防具 1～3 条（前缀机制、后缀数值），护符 1 条；数值在每档的范围里随机；同稀有度的数值词条可以叠加 | ② | 已上线；数值随机游戏内未完整验证 |
| 第五护符栏 | 原版的「誓约」栏改成护符栏 | ② | 已上线 |
| 骨灰稀有度 | 骨灰带强化召唤物的词条和改玩法的前缀（比如召唤物倒下时爆炸），传说多召唤一只 | ①② | 已上线 |
| 战技 | 145 种专属战技做成战灰，能装到别的武器上；战技伤害随稀有度提高；14 种范围战技扩大到 8 米 | ② | 已上线 |

| 向星辰许愿 | 花卢恩直接拿当前地区的成品装备；每个角色开局有 30 次免费 | ① | 已上线 |
| 暗黑商店 | 卢恩买随机武器，龙心脏买护符和战灰，星光碎片买法术和祷告；按区域头目分阶段上架；可以回购 | ① | 已上线 |
| 一键出售、锁定、武器回收 | 按类别和稀有度一次卖掉；锁定的不卖；回收武器换重铸石 | ①④ | 已上线 |
| 商人和支线 | 商人卖当地的未鉴定物品和限购的传说武器，对话就给铃珠；支线奖励换成同一件装备的史诗版本；英雄的防具换成三词条的传说 | ① | 已上线 |
| 八档难度 | 轻松到不可能，随时切换，记在存档里 | ⑤ | 已上线 |
| 「死亡」「不可能」 | 击败玛利喀斯后单向进入；小怪和头目统一到后期强度；12 个头目换成新的招式和阶段 | ⑤ | 已上线 |
| 魇化精英、魇火、魇印 | 少数小怪魇化成精英；它的词条变成临时生效的魇火；夺取够次数刻成永久生效的魇印 | ②⑤ | 已上线 |
| 七道咒痕 | 七条区域诅咒同时生效；区域头目首杀给碎片，集满反转成祝福 | ⑤ | 已上线 |
| 超限锻造石 | 让补正或减伤率超过原本的上限；防具石还能把一条词条升一档稀有度 | ⑤ | 已上线 |
| 许愿石 | 每颗加 1 点能力值、升 1 级，不花卢恩 | ⑤ | 已上线 |
| 对勇于挑战者的馈赠 | 「死亡」以上每次在赐福休息后，第一次死亡时满状态复活 | ⑤ | 已上线 |
| 斗技场试炼 | 三座竞技场，花星光碎片打魇化精英和头目轮流出场的连战 | ①⑤ | 已上线；需要开敌人随机 |
| 异常重做 | 所有敌人都会中发狂和咒死；发狂扣血削韧，咒死改成降低其他异常抗性 | ② | 已上线 |
| 移动和便利 | 蹬墙跳；不受坠落伤害；在哪都能传送；开局有灵马和召魂铃；赐福记忆传送不掉卢恩；任意赐福都有「更多选项」；卢恩银行 | ④ | 已上线 |
| 战技改动作 | 坩埚之翼战技改成飞行；唤声船能乘船 | ② | 已上线；唤声船游戏内未完整验证 |
| 庆典油脂 | 持有的卢恩越多伤害越高，持续消耗卢恩 | ② | 已上线 |
| 敌人随机 | 用玩家自己下载的随机器；启动器「敌人设置」调精英多少、把一部分普通敌人换成头目 | ⑤ | 已上线；随机器不随包 |
| 联机 | Seamless Co-op：全队用房主的世界，敌人只让房主改，魇化由房主抽 | ④ | 开发中，按钮隐藏 |
| 自制敌人随机器 | 不依赖外部随机器 | ④ | 暂停（2026-10-29） |

## 操作

原版操作不变，各设备的按键见[界面与无障碍](06%20%E7%95%8C%E9%9D%A2%E4%B8%8E%E6%97%A0%E9%9A%9C%E7%A2%8D.md)。新加的动作：

- **鉴定、购买、许愿、出售**：在赐福菜单最上面的「暗黑重铸」里选，用的都是原版的菜单和确认框，和原版的赐福操作一样顺手。
- **装备工坊**：画在游戏画面上的一个界面，手柄、键鼠都能用。按 `/` 搜索，可以直接打拼音（全拼或首字母）；继承、重铸、超限页按 F 筛选词条，手柄在列表第一行再按上。继承成功时有一声铁砧声。
- **锁定**：在背包或仓库里选中装备，弹出菜单最下方选「锁定」或「解锁」。
- **蹬墙跳**：贴着墙再跳一次，不会触发跳跃攻击。
- **飞行**：用坩埚之翼的战技起飞，一直向前飞，撞到墙会停下。
- **召唤骨灰**：在哪都能召唤，不需要附近有召唤点。

## 成长

- **一轮循环之内**：
  - 背包里的新装备逐步换代；
  - 锻造石把新武器强化到 +5，每级 1 块，石头种类看稀有度；
  - 卢恩用在升级、定向鉴定和许愿上。
- **跨区域**：
  - 掉落的稀有度按六个地区档提高，见[系统与经济](02%20%E7%B3%BB%E7%BB%9F%E4%B8%8E%E7%BB%8F%E6%B5%8E.md)；
  - 击败区域头目，商店上新；
  - 新装备的记录跟着存档格子走；新建角色时，开局装备、遗物和骨灰重新随机。
- **长期目标**：
  - 凑出一套毕业流派：传说武器、三词条防具、五个护符栏里互相配合的词条；
  - 进入「死亡」「不可能」：反转七道咒痕、刻满魇印、超限主力装备、用许愿石加点；
  - 斗技场的 8 波连战全部打完。

## 挑战与失败

- **难度提升方式**：
  - 敌人血量按所在地区提高；开了敌人随机，按被放到的位置算。小怪血量的曲线到幽影之地末端约 2 万，头目按地区 ×1 到 ×5.1。
  - 精英的比例从前期的 2.5% 增加到幽影之地后期的 15%；前期不放古龙。
  - 难度档：大师造成的伤害 ×0.5、受到的伤害 ×1.5；「死亡」×0.45 / ×2.22，「不可能」×0.4 / ×2.5。
  - 「死亡」以上：前期地区也是后期强度，异常抗性大幅提高，再加上魇化精英、七道咒痕和改版头目。
- **失败的代价**：
  - 同原版：死亡时掉落身上的卢恩，可以回去捡；存在卢恩银行里的不会掉。
  - 魇火在死亡时全部消失。
  - 在斗技场里死了，收回这次试炼得到的奖励。
  - 进入「死亡」本身是放弃一个选择：这个角色再也回不到「大师」及以下。
- **重新投入的方式**：
  - 在哪都能传送，赐福记忆传送不掉卢恩；
  - 「头目复活」可以重打任何头目；
  - 「大师」及以下随时调低难度；
  - 「死亡」以上每次休息后，有一次馈赠复活。
