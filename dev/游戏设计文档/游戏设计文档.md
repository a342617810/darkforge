# 游戏设计文档：暗黑重铸（Darkforge）

按 v0.10.12（2026-11-17）的实际实现整理。数值以 `launcher\reroll\settings.json` 为准，这里只记当前值和思路。写着「游戏内未完整验证」的，是代码和离线测试做完、还没在游戏里逐项看过的。

## 提案

想把交界地当成一款刷宝游戏重新玩一遍的人，可以从这里开始。原版的武器、防具和护符不再掉落，取而代之的是要在赐福鉴定的新装备：四档稀有度，随机的补正、属性和战技，一百多种词条，能凑出姿态舞、环绕法球、反击回血、空战等十几个流派。打完本体和幽影之地，击败「黑剑」玛利喀斯，就能步入「死亡」，那里有七道咒痕、魇化精英和超限锻造石。

## 设计支柱

1. **每件装备都是掉出来的**：原版武器、防具和护符退出掉落，宝箱、地上、尸体、支线奖励、黄金卢恩和商人都改成给新装备或未鉴定物品。每个新系统都要往「打怪 → 掉装备 → 变强」这条线上送东西。
2. **词条改变打法**：防具的前缀改机制、后缀加数值，武器带特效，传说里有改写规则的「规则改变器」。只加数值、又和已有词条重复的，并进同一个变体组。流派词条按「引擎 → 放大 → 收割」成套设计。
3. **长在原作里**：只用原作已有的人物、地点和术语，文字照原版说明的写法，图标照原版的画法。新功能都挂在赐福菜单里，不加 NPC，不加配音。
4. **开箱即玩，不碰原版**：解压后双击「启动.bat」就能玩。独立存档，启动前自动备份，在线更新。玩家不用装任何工具，所有功能都是按钮和对话框。
5. **难度越高，给得越多**：八档难度随时切换，越难卢恩和观察力越多。「死亡」「不可能」只能单向进入，换来超限锻造石、许愿石、魇印这些只在那里拿得到的东西。

## 目标受众

- **核心玩家**：通关过本体和幽影之地、想找新鲜感的中文法环玩家。熟悉魂类操作，愿意在背包里比较词条，但不想自己装 mod 工具。
- **他们现在玩的游戏**：
  - 艾尔登法环和它的大型改版（法魂 The Convergence、ELDEN RING Reforged、RNG Lands）；
  - 暗黑破坏神、流放之路；
  - 杀戮尖塔这类构筑游戏。
- **他们在这些时候流失**（都在实际反馈或诊断包里遇到过）：
  - 第一次启动：找不到游戏路径、被杀毒软件拦下、要自己下载随机器；
  - 游戏更新后版本对不上；用的不是 Steam 正版，联机初始化失败；
  - 前期：装备太多，看不懂词条；
  - 中期：掉的史诗、传说能力需求太高，用不上；
  - 崩溃以后：不知道该做什么。
  - 已经做了的应对：
    - 自动找游戏路径，不用隐藏窗口启动；
    - 启动前检查游戏版本；
    - 词条百科、一键鉴定，鉴定结果偏向当前加点；
    - 一键导出诊断包。
- **次要玩家**：
  - 想要更难挑战的老玩家（「死亡」以上难度）；
  - 暗黑、流放之路、杀戮尖塔的玩家；
  - mod 和整合包玩家（看重安装简单、自动更新）；
  - 英文圈玩家，要等授权处理完才面向他们发布。

## 对标游戏

| 游戏 | 借鉴什么 | 舍弃什么 |
| --- | --- | --- |
| 暗黑破坏神 3 | 未鉴定 → 鉴定；四档稀有度和配色；前缀 / 后缀词条；传说装备改规则 | 交易、赛季、大秘境这些核心循环以外的玩法；没有上限的数值膨胀：每档词条有范围，超限也只到 ×1.1 / ×1.2 |
| 流放之路 | 血魔法和低血流派；规则改变器（只出在传说上，同时只能戴一个） | 天赋树和通货交易：成长只靠装备和原版加点 |
| 杀戮尖塔 | 流派的设计方法「引擎 → 放大 → 收割」；姿态切换、充能球、壁垒这些流派原型 | 卡牌、回合制和随机地图本身 |
| RNG Lands（同类 mod） | 词条库最初从它的包里提取；掉落按地区分六档 | 固定编号的成品装备、它的基础包、法术和祷告（2026-10-26 起全部去掉，只留词条） |
| 法魂 The Convergence（同类 mod） | 在任何地方都能召唤骨灰；联机时所有人的文件完全一致 | 重做职业和法术体系 |

## 范围

- **首个公开版本包含**（v0.10.12 都已经有了）：
  - 新装备系统：掉落、鉴定、装备工坊、暗黑商店、出售和锁定、许愿、武器回收；
  - 骨灰稀有度和词条；
  - 八档难度；「死亡」「不可能」整套玩法：咒痕、魇化精英、魇印、超限、许愿石、馈赠、改版头目；
  - 斗技场试炼、卢恩银行，移动和便利方面的改动；
  - 启动器：网页界面、在线更新、备份和恢复、诊断包、敌人设置、模组文件夹。
- **首个公开版本不包含**：
  - 联机（按钮隐藏）；
  - 新地图、新 NPC、配音；
  - 自制的敌人随机器（2026-10-29 评估后暂停）；
  - 地面讯息（叙事方案的阶段三）；
  - 武器质变、武器词条升级。
- **以后再定**：
  - 联机什么时候上线（要等两台电脑的实测）；
  - 英文版和 N 网发布；
  - 「一键重随敌人」自动点随机器按钮的做法怎么改；
  - 授权没定的改版头目是去掉，还是让玩家自己下载；
  - 完整整合包的公开下载地址。
