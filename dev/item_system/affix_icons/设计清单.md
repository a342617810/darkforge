# 新词条图标设计清单

2026-11-11，用户确认的风格是 icons_charm.py 那一版：每个词条画成一件**护符 / 饰品**。

**风格要求：**
- 用金属铸造、镶嵌宝石、骨雕或绳结来做，带挂环、链子或绳子，看起来是能戴的东西。
- 颜色压暗、去饱和，积灰和磨损要重，发光很克制，尽量贴近原版。
- 不拼接原版图标的像素，图上不放文字。

**技术约定：**
- 160×160 透明底，物件占满约 9 成（`fit=0.9`）。
- 渲染参数统一用 icons_charm.DARK。
- 输出文件为 `out/charm_<key>.png`。

下表中「挂法」只是建议，同一批里挂环、链、绳要轮流用。
