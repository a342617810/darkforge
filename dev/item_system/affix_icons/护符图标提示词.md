# Charm Icons: 67 Separate Images

Generate 67 images, one for each numbered prompt below. Each prompt is an independent image request: make exactly one image per prompt, in order from 01 to 67. Do not combine prompts, do not put several items in one image, and do not make a grid, collage or contact sheet.

Rules for every image:
- Square 1:1, at least 1024 × 1024 pixels.
- Exactly one object, the charm the prompt describes. Centered and complete, with a small margin on every side, filling about 90% of the frame. The whole hanging ring, chain or cord loop must stay inside the frame; nothing may run off the image edges.
- A plain, uniform, flat neutral gray background. No cast shadow, no floor, table or cloth, no vignette or gradient.
- No text, letters, numbers, watermark, frame or border inside the image.
- Style: a realistic game inventory icon in the manner of Elden Ring's talisman icons. Dark, desaturated, tarnished and worn, with any glow kept subtle. It must clearly be a wearable charm with a ring, chain or cord to hang it by. Not cartoonish, not a painting, not a scene.
- Follow each prompt's details exactly, including every "not ..." instruction.
- Label each result with its number (for example "01") outside the image, so the images can be matched to the prompts.
