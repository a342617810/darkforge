# 光效对照：词条效果 ↔ 人物身上的光效

整理于 2026-10-28。记录每条自己做的词条在人物身上挂什么光效、从原版哪里借来的、什么时候挂；以及换光效的方法和找候选的结果。

相关：`bd设计.md`（流派和积木词条）、`词条一览.md`（词条说明）、`extract_affixes.py`（定义：`VFX_*` 常量、`RULE_AFFIXES` / `CUSTOM` 的 `rows`）。

---

## 1. 基本概念

- **光效**：效果参数（SpEffectParam）的 `vfxId` 指向光效参数（SpEffectVfxParam）的一行。效果挂在人物身上时显示这行光效，摘掉就消失。
- 一行光效里主要看：
  - **持续特效**（`midstSfxId`）：效果在的时候一直播；
  - **开头特效**（`initSfxId`）：挂上的那一下播一次；
  - **挂点**（`midstDmyId`）：特效挂在身体哪个位置（220、905、800、200 是原版常见的几个）。
- **状态图标**是效果参数的 `iconId`。游戏在效果快到期时会让图标闪烁，所以长期挂着的效果要做成**不限时**（`effectEndurance = -1`），由积木引擎负责摘（见第 3 节）。
- 我们用的光效都是原版现成的光效行，只有霜铠自己建了一行。

### 2.1 霸王为什么拆成两个效果

- 真正挡硬直的是 0.3 秒的效果（照忍耐 1650 复制）：玩家脚本在战技状态里每帧挂，挂着才算有霸体。
- 0.3 秒的效果图标永远处在「快到期」，会一直闪。所以这个效果**不带图标和光效**。
- 图标 20430 和忍耐光效 8570 放在另一个**不限时**的效果里：玩家脚本在霸体还没用掉时每帧发事件 `armor`，积木引擎看到就挂，`armor` 不再发（战技结束或霸体用掉）就摘。

## 3. 规则

1. **引擎管的效果不限时**：`while` / `stack` 挂的效果写 `effectEndurance=-1`。
   - 积木引擎每帧对照「该挂的」和身上实际有的：该有没有就挂，不该有却有就摘。
   - 摘下装备、读档、换稀有度留下的效果也会被清掉。
   - 不再每 0.5 秒续一次（续期会让限时效果的图标一直闪，用户 2026-10-28 报的）。
2. **一次性的效果**（`on` 挂的，比如转念的 1.5 秒蓝光）可以限时，自然消失，不归引擎管。
3. **开头特效**：引擎管的效果只在挂上那一下播开头特效。比如静心 / 怒意，每次切换持握会各播一次，可以接受；但不要给每帧都会重挂的效果（比如霸王 0.3 秒那个）带光效。
4. **颜色区分**：同时可能出现的光效尽量选不同颜色（静心绿、怒意红、心流金、转念蓝），避免叠在一起分不清。

## 5. 换光效

- 改 `extract_affixes.py` 里的 `VFX_*` 常量（姿态舞）或对应词条 `rows` 里的 `vfxId`（霸王的 `look`），重跑提取：
  `launcher\python\python.exe -X utf8 dev\item_system\extract_affixes.py`
- 不用改 DLL。从启动器重进游戏生效；已经拿到的装备也会变，光效挂在效果上，不在装备本身。
- 效果编号不会变（只锁装备记录里存的编号，光效所在的效果行是内部行）。
