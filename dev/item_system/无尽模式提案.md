# 无尽模式提案（2026-11-19，待确认）

用户 2026-11-19：「开始做无尽模式的提案吧 无尽模式只在死亡以上难度开放 目前每波只加敌人血量5% 奖励封顶是每层肃清之后10个」，接着「然后玩家可以选择保存进度退出」。

前面的实验、试负载、几个方案的比较记在 `无尽模式方案.md`。这份只写定下来的玩法和怎么做。

## 结论

可行，大部分零件已经有了：

- **斗技场试炼的整套流程**：雕像菜单、传送、一波一波出场、问「继续」、发奖励、死了收回、雕像旁复活、联机房主带队。
- **生成器复活**（实验第五～八轮）：打死的敌人可以用它自己的生成器叫回来，同一只、满血，魇化和描边重新挂上，AI 正常。
- **池子**：一张竞技场图同时最多读进来约 58 只，所以一批 50 只（16 Boss + 32 精英 + 2 粪金龟）。每次启动换一批，4 批轮下来能轮到全部候选（b05e9fb）。

要新做的：
- 雕像菜单里的无尽入口，只在死亡以上开放；
- 无限波次：一波一波现抽，用完的靠复活；
- 每波血量 +5%；
- 奖励封顶；
- 保存进度和续上；
- 联机同步。

## 玩法

带「★」的是用户定的，带「待定」的还要你定。

**入口**
- ★ **只在死亡以上开放**：雕像菜单在三种场次后面加「无尽试炼」，只有当前角色是死亡或不可能档时才显示。按档位标记 9956（死亡）、9957（不可能）判断。
- 联机时看房主的档：房主是死亡以上才显示，同现在死亡以上联机的规则。
- 有保存的进度时显示两项：「无尽试炼：继续（第 N 波）」和「无尽试炼：重新开始」。重新开始先确认一次，会清掉保存的进度。
- 花费：建议 3 个星光碎片（待定）。续上要不要再扣（待定，建议也扣：碎片照原版数量，不扣的话保存退出就没有代价）。

**波次**
- 精英波和 Boss 波交替，同现在：精英波 2 只魇化精英（可能换成粪金龟），Boss 波 1 个 Boss。没有尽头。
- 每打完一波问「继续挑战下一波吗？」：
  - 「是」：出下一波；
  - 「否」：**保存进度退出**（★），已经发的奖励保留，记下下一次从第几波开始，传回进来的那个雕像旁。

**越打越强**
- ★ **只加敌人血量，每波 +5%**。第 n 波是 ×(1 + 5% × (n − 1))，第 1 波不加（待定：第 1 波要不要也 +5%）。
  - 不再用试炼「每 2 波 +10%、最多 +40%」那一套。
  - 血量效果行做到一个上限，例如第 200 波（×10.95），之后不再涨（待定）。
- 这些敌人身上原有的照旧：死亡以上的血量 / 攻击倍率、魇化（血量 ×2、词条；死亡以上带两条的几率照现在的 elite_two）、随机器的强度缩放。攻击力不另外加。

**出场、用完了怎么办**
- 每一波从这一批 50 只里抽，优先这一场还没出过的。
- 都出过了就从倒下的里挑最久没出场的，用它的生成器复活（同一只，满血，重新魇化）。
  - Boss 16 只：Boss 波是偶数波，第 34 波起开始复活；
  - 精英 32 种、每波 2 只：精英波是奇数波，第 33 波起开始复活（有精英位换成粪金龟的话还会晚一点）。
- 粪金龟钻地逃跑以后算不算死、能不能再叫，要先测；不能叫的话就不再出。

**奖励**
- 每打完一波发未鉴定物品，稀有度照这个竞技场固定的那一档。件数照现在的规则随波次涨：第 j 个精英波 2 × j 件、第 j 个 Boss 波 j 件，王城 ×2。
- ★ **每波封顶 10 件**：宁姆格福、盖利德的精英波第 5 次、Boss 波第 10 次起，王城精英波第 3 次、Boss 波第 5 次起，都是 10 件。
- Boss 波照旧多一个骨灰。
- 试炼的「全部打完多给」「退还碎片」无尽模式没有，因为没有打完的时候。

**死了**（待定）
- 收回这次进场以后发的奖励（同试炼）；之前保存退出时已经保留的不收回。
- 进度：
  - 建议 A：回到上次保存的那一波；
  - B：清零，从第 1 波重来。

**记录**
- 每个角色、每个竞技场记最高波数，雕像菜单的无尽那一项写「最高第 N 波」（待定要不要）。

## 技术方案

**重随（rr/arena.py）**
- 设置加 `endless`：开关、花费、每波血量 +5%、血量做到第几波、每波最多几件。写进 arena.txt 的 `endless` 行。
- 血量效果行：每波一行（maxHpRate 1.05、1.10 ……）。新开一段效果编号，现在试炼只有 7319970～73 四行。
- 生成器：三个竞技场每个部件都配一个。把实验第六～八轮的代码转正，`generator_test` 设置去掉。
- 存档标记：每个竞技场「保存的进度（第几波，10 位）」+「最高波数（10 位）」，共约 60 个。要在 dev\event_flags 扫一段空号，并定标记护栏（联机时房主的值盖不掉队员的）。

**地图事件（sc/arena.py）**
- 部件事件改成循环：第一次出场用启用、以后用叫生成器；然后 AI 关、无敌，就绪，开打，Boss 挂血条，等它死、点亮死亡标记、关血条，从头再来。复活前熄掉死亡标记。
- 雕像菜单：无尽那一项按档位标记显示，有进度时分「继续 / 重新开始」，确认框写明死亡以上、花费和死了怎么算。

**dark_core（arena.rs）**
- Run 加「无尽」：没有总波数，出场顺序一波一波现抽（房主抽），出过的记下来，用完的走复活。
- 每波挂这一波的血量行：wave_effects 已经有，换成按波次那一行。
- 奖励封顶 10 件。
- 保存退出：选「否」时写进度标记（下一波），奖励保留，传回雕像。续上：从标记里的那一波开始，血量按那一波算。
- 死了：按定下来的规则收回奖励、改进度。
- 最高波数记录。
- arena_run.txt 照现在的用法，中途退出游戏读档时接上或结束。
- F9「斗技场试炼测试」加：进无尽（从第 N 波）、清掉进度；生成器实验的按钮去掉。

**联机（G1～G11）**
- 房主决定每一波出哪几只、复活哪几只，写进现在每秒发的进度里；队员照着点亮出场 / 复活标记。魇化词条由房主广播，同现在。
- 阵容：联机按日期选批，两边同一批（b05e9fb 已做）。
- 进度、记录按房主的；队员各发各的奖励。
