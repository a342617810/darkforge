训练木桩 + 训练场整备点（圆桌厅堂能战斗的区域）用的固定文件，运行时只用 Python 读写（不需要 .NET）：

m11_10_00_00.msb.dcx：圆桌厅堂地图 = 原版 + 下面 2 个部件 + 2 个特效区域（DFLT 压缩）。离线用 data\msbtool 从原版（randomizer\diste\Vanilla）做：
  add   c5600_9990 c5600 敌人参数 56009900 Think 0 (-300.99353, -32.61, -295.56427) 朝向 -119.86379 碰撞 h016000（木桩，ELDEN VINS 的位置）
  clone c1000_9005 → c1000_9011 实体 0 (-303.15, -31.85, -296.83) 朝向 -119.86379 碰撞 h016000（整备点的对话角色，照抄双子老妪的）
  talk  c1000_9011 699001110 500020090（对话脚本 t699001110.esd；敌人参数 500020090 = 双子老妪那份换了名字「整备」，rr/dummy.py 建）
  cloneregion 11102100 → RNG_station_sfx_811100、11102101 → RNG_station_sfx_811101，放在对话角色上方 0.5 米（-31.35）
    （整备点的外观：大赐福桌上那团赐福光的特效区域；没有实体编号，大赐福的事件 11102100 删不到它们，一直显示）
  部件的实例编号（Unk08）= 名字末尾的数字，msbtool 自动设（不然游戏会把复制出来的当成原来那个）。
  整备点在木桩身后约 2.5 米（那里是抬高约 0.8 米的台子，地面约 -31.85）。
  试过不行的外观：法魂那个位置的 AEG099_053 是看不见的交互点；没登记的赐福 AEG099_060 不显示；双子老妪模型放在这里会埋进台子。

m11_10_00_00.talkesdbnd.dcx：圆桌对话包 = 原版 + t699001110.esd（msbtool bndadd，内容先照抄双子老妪的 t600001110.esd）。

启动时 scripts.py（sc\training.py）：
  地图：把随机器对这张图的改动（替换入侵的阿尔贝里奇）按字节同步到固定地图上；
  对话包：来源包（随机器输出 / 原版）里的 17 个脚本原样换进来，t699001110.esd 换成整备点的菜单（更换战灰 / 记忆法术 / 恢复 / 离去）；
  事件脚本：加事件 11102990——对话里选「恢复」点亮标记 11109990，事件看到就像在赐福休息一样恢复（2004[47] + 原版效果 30100，照抄法魂 mod，不刷新敌人）；
  菜单选项判断写成「取选择结果 == n」（照抄法魂 / 难度菜单；双子老妪那种存寄存器的写法拆出来就失效了）；
  菜单文字：menu_dlc02 的 80090100~80090103。

为什么不是赐福：圆桌厅堂的赐福是游戏写死的，加第二个也会被当成「大赐福」（显示在大赐福休息、落座位置不对、地图上没有传送点）。
